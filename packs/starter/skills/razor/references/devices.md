# Devices and notifications

`razor devices add <name>` without `--address` enrolls the phone or another client and shows its full-access key once (`machines.md`). Read `machines.md` for pairing servers and remote terminals, `security.md` for the full-access device key, and `configuration.md` for notifications. Each Razor home has its own server and settings. A network listener is plain HTTP; use a private network and pair only trusted devices. Changing `server.address` requires a restart: follow the restart guidance in troubleshooting. Use the documented `razor devices` commands for the installed version; deliver pairing secrets through the person's secure channel, never in a record or message.

The starter pack's `notify` and `ask` programs show desktop notifications. Its commented ntfy examples can send them to a phone; copy the chosen lines into the person's config and use a private, unguessable topic. A question still waits for an answer in Razor. A program named by `ask` can answer by printing a response and exiting successfully, so check its output and behavior before configuring it. Test delivery with the person's permission and avoid sending sensitive text to an untrusted service.
