# Razor

Razor is a terminal app and server for running coding agents such as Claude and GPT. The server keeps sessions running after you close the terminal, and agents can hand work to helpers that work on separate Git branches.

Install on Linux (x86-64 or ARM64) or an Apple silicon Mac:

```sh
curl -fsSL https://github.com/treygoff24/razor/releases/latest/download/install.sh | sh
```

The installer checks the download and starts `razor setup` for sign-in when run in a terminal. The guides ship with Razor. On a standard install, open `~/.local/share/razor/current/docs/README.md`.
